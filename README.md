# OSE11P Multi-Vehicle Diagnostics

Android diagnostics and logging project for Delco $11P and generic OBD-II vehicles using Bluetooth ELM327 adapters, with optional Gemini-assisted diagnostics.

## Source bundle
See `release/OSE11P_MultiVehicle_ELM327_Gemini.zip` for the complete Android Studio project as supplied.

## Important
This is a development snapshot, not a verified production release. The Android project has not been fully built and tested on physical vehicles/adapters. Generic OBD-II coverage is limited to supported standard PIDs and adapter capabilities; manufacturer-specific modules and protocols require additional implementation and hardware. AI output is advisory only. Never use it as a substitute for proper instrumentation, calibration, or safe testing.

Do not commit API keys. Any Gemini key previously pasted into chat should be revoked and replaced; keep keys out of source control.
