# OSE11P Multi-Vehicle Diagnostics

Android diagnostics and logging project intended for Delco $11P and generic OBD-II vehicles using Bluetooth ELM327 adapters, with optional Gemini-assisted diagnostics.

## Project status
Repository initialised. The complete Android Studio source bundle has not yet been uploaded; the initial development ZIP is available in this ChatGPT conversation as `OSE11P_MultiVehicle_ELM327_Gemini.zip`.

## Important limitations
This is a development snapshot, not a verified production release. The Android project has not been fully built and tested on physical vehicles/adapters. Generic OBD-II coverage is limited to supported standard PIDs and adapter capabilities; manufacturer-specific modules and protocols require additional implementation and hardware. AI output is advisory only.

Do not commit API keys, signing files, or credentials. Any Gemini key previously pasted into chat should be revoked and replaced. Keep API keys out of source control and use a secured backend for a distributed app.
